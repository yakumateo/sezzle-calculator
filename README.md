# Sezzle Calculator

A full-stack calculator: a **React + TypeScript** frontend that consumes a **Go** REST microservice to perform
basic and advanced arithmetic operations.

> Work in progress. Each section below is completed as the corresponding part is built.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Advanced operations: power, square root, percentage

## Tech stack

| Layer    | Technology                                   |
|----------|----------------------------------------------|
| Backend  | Go (standard library `net/http`)             |
| Frontend | React, TypeScript, Vite, Vitest              |
| Tooling  | Docker Compose, OpenAPI 3 + Swagger UI       |

## Project structure

```
backend/    Go REST microservice
frontend/   React + TypeScript web client
docs/       Architecture decision records
```
